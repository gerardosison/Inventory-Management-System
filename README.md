# Raylib Inventory System

Raylib Inventory System is a C-based Inventory Management System developed as a System Project. The system is designed to simplify and digitize the daily operations of stock and product management by providing an organized platform for tracking inventory records, products, purchases, and restocks. It replaces traditional manual processes with a centralized system for managing product information, stock levels, sales, and transaction summaries.

The project follows structured programming principles and was developed using C with the Raylib library to provide a user-friendly desktop application.

## Features

* Login Authentication
* Record Management (Create, Rename, Switch, Delete)
* Product Management (Add, Rename, Edit ID, Edit Price, Delete)
* Purchase Tracking
* Restock Management
* Search and Sort Products
* Transaction Summary Generation

## Technologies Used

* C
* Raylib
* Text Files Database
